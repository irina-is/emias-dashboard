# Деплой-портал — установка на сервере

## 1. Сборка (на машине разработчика)

```bash
cd deploy-portal
mvn clean package -DskipTests
# Результат: target/deploy-portal.jar
```

## 2. Копирование на сервер

```bash
scp target/deploy-portal.jar root@<IP>:/opt/deploy-portal/deploy-portal.jar
```

## 3. Настройка пользователя и прав

Портал должен иметь право перезапускать сервис `emias-dashboard` через sudo без пароля.

```bash
# На сервере:
useradd -r -s /bin/false deployer          # если нет отдельного пользователя
chown deployer /opt/deploy-portal/ -R

# Разрешить только нужные команды без пароля
echo "deployer ALL=(ALL) NOPASSWD: /bin/systemctl stop emias-dashboard, /bin/systemctl start emias-dashboard" \
  > /etc/sudoers.d/deployer
chmod 440 /etc/sudoers.d/deployer
```

> Если приложение запускается от root — можно пропустить этот шаг и убрать `sudo` из команд  
> в `DeployController.java` (заменить `"sudo", "systemctl"` на просто `"systemctl"`).

## 4. Конфигурация

Создать `/opt/deploy-portal/application.properties`:

```properties
deploy.username=admin
deploy.password=ВАШ_ПАРОЛЬ
deploy.jar-path=/opt/emias-dashboard/dashboard-1.0.0.jar
deploy.service-name=emias-dashboard
```

## 5. Systemd-сервис

Создать `/etc/systemd/system/deploy-portal.service`:

```ini
[Unit]
Description=Deploy Portal
After=network.target

[Service]
User=deployer
WorkingDirectory=/opt/deploy-portal
ExecStart=/usr/bin/java -jar /opt/deploy-portal/deploy-portal.jar \
  --spring.config.location=/opt/deploy-portal/application.properties
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable deploy-portal
systemctl start deploy-portal
```

## 6. Nginx (добавить в существующий конфиг)

```nginx
location /deploy {
    proxy_pass http://localhost:8081;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    # Увеличить лимит для загрузки JAR
    client_max_body_size 200M;
}
```

После этого портал доступен по адресу: `http://<IP>/deploy`

## Обновление портала

```bash
mvn clean package -DskipTests
scp target/deploy-portal.jar root@<IP>:/opt/deploy-portal/deploy-portal.jar
ssh root@<IP> systemctl restart deploy-portal
```
