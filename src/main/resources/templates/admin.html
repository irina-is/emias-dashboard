Загрузка фактических данных — 4ДИ Гепатит С

Загрузите Excel-файл с еженедельными фактическими данными по одному из трёх проектов.
Формат файла: Столбец A — название МО, Столбец B — накоплено (всего с начала), Столбец C — за последнюю неделю (необязательно). Первая строка — заголовок (пропускается автоматически).

Подсказка: Названия МО в файле должны точно совпадать с плановыми (допускаются отличия в кавычках и регистре). После загрузки данные сразу отобразятся на дашборде Гепатит С.
