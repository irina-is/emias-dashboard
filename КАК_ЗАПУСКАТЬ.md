# Как запускать и собирать проект

## Локальный запуск

1. Открой **Run → Edit Configurations...** в IntelliJ
2. Выбери **DashboardApplication**
3. Найди поле **Active profiles** и напиши туда: `local`
4. Нажми **OK**
5. Запускай как обычно (зелёная кнопка ▶)

После запуска приложение доступно по адресу:
**http://localhost:8081/spec/login**

---

## Сборка jar для продакшна

Выполни в терминале (в папке проекта):

```
mvn clean package -DskipTests
```

Готовый jar будет в папке `target/`. Его нужно залить на сервер.

---

## Важно — не делай этого!

Не добавляй в файл `application.properties` строчку:

```
server.servlet.context-path=/spec
```

Если она там появится — на продакшне будет ошибка 404.

Для локальной разработки эта настройка уже прописана в отдельном файле
`application-local.properties` — он подхватывается автоматически когда
указан профиль `local` (шаг 3 выше).
